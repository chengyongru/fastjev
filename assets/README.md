# Visual assets

`fastjev-logo.svg` is the shared README wordmark. Its `FastJev` lettering uses
outlined Inter 700 glyphs, so the asset has no runtime font dependency. The
abstract F/bolt mark and `Jev` use separate blue-to-purple gradients.

`fastjev-cover.webp` is an optimized WebP derivative of the cover supplied by
the project maintainer. It is shared by the English and Simplified Chinese
READMEs.
